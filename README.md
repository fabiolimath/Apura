# Apura

Painel de apuração das eleições 2026 (1º turno), com dados do TSE.

## Publicação

A página (`index.html`) é publicada no GitHub Pages pelo workflow
`.github/workflows/pages.yml` a cada push na branch `main` (incluindo merges de PR).
Também é possível disparar manualmente em **Actions → Publicar no GitHub Pages → Run workflow**.

Endereço: https://fabiolimath.github.io/Apura/
